# Brace — релизы

Витрина дистрибутива **Brace** — десктопного приложения для создания и
управления HTML5-баннерами.

Здесь лежат только собранные установщики и `latest.yml` — файл, по которому
установленное приложение узнаёт о новых версиях. Исходный код в этот
репозиторий не попадает.

## Скачать

Последняя версия — на странице [Releases](../../releases/latest).
Нужен файл `Brace-<версия>-win-x64.exe`.

Файлы `.blockmap` рядом с установщиком трогать не нужно: по ним приложение
докачивает обновление кусками, а не целиком.

## Обновления

Приложение проверяет обновления само и предлагает поставить новую версию,
когда она выходит. Скачивать установщик заново для этого не нужно — вручную
сюда приходят только за первой установкой.

## Платформы

Пока собирается только сборка под Windows (x64).
